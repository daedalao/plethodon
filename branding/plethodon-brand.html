SiskiyouPlethodon

An independent build of the Gecko browser engine for PowerPC — 32-bit G4 and 64-bit big-endian first. Built from Mozilla Firefox source code; not affiliated with or endorsed by Mozilla.

The name

The salamander of the forest the Biscuit Fire burned

The Biscuit Fire

Lightning started five fires in the Kalmiopsis Wilderness of the Siskiyou National Forest; they grew into one and burned into October.

Ignition
13 July 2002, lightning
Area
499,965 acres
Where
Siskiyou Mountains, SW Oregon & N California
Record
Oregon's largest recorded forest fire

The Siskiyou Mountains salamander

Plethodon stormi — a small, lungless salamander, dark brown with brassy flecks, breathing through damp skin under mossy talus.

Range
Siskiyou Mountains only (Applegate drainage, Seiad Valley)
Habitat
Talus slopes under mature forest canopy
Status
Endemic; Oregon conservation strategy species

Plethodon is the salamander's genus; the Siskiyou Mountains salamander is Plethodon stormi. The salamander is the creature old stories say lives in fire, and this one lives in the forest the Biscuit burned. The browser is the same idea: the Gecko engine carried onto hardware the upstream project no longer builds for, and doing fine there.

The mark

16–24 px use the simplified mark (heavier body, no flecks, talus or ridge glow); 32 px and up use the primary mark.

SiskiyouPlethodon
Plethodon

Do

  • Keep clear space of one quarter of the mark's width on every side.
  • Use the simplified mark below 32 px and the symbolic mark wherever a single colour is required.
  • Set the wordmark in Rokkitt: "Siskiyou" Medium, "Plethodon" ExtraBold, one word, no space. The short-name lockup is "Plethodon" alone.

Don't

  • Draw a fox, a globe, or any creature wrapped around a circle.
  • Use an orange-to-purple gradient anywhere.
  • Recolour the salamander red or orange; it's umber with brass flecks.
  • Put the Firefox name or logo in the product name, icons, window titles or desktop entry.

Naming convention

Every name the browser uses

WhereNameRule
Full nameSiskiyouPlethodonOne word, camel case, capital S and P. Never "Siskiyou Plethodon" with a space. Used where the product introduces itself: About dialog, desktop entry name, website, announcements.
Short namePlethodonEverywhere Firefox itself just says "Firefox": menus, window titles, taskbar, "Quit Plethodon", "Plethodon Settings".
Machine nameplethodonOne identifier for the pacman package, the binary (/usr/bin/plethodon), the install directory (/usr/lib/plethodon/) and MOZ_APP_NAME.
Window identityplethodonRemoting name, Wayland app_id and X11 WM_CLASS; the desktop entry is plethodon.desktop so docks match windows to the launcher.
Profile~/.plethodon/Separate from any Firefox profile on the same machine.
Branding directorybrowser/branding/plethodon/Selected with --with-branding=browser/branding/plethodon in place of --enable-official-branding. Holds the icons (default16.png–default256.png) and the brand strings: brand-full-name and brand-product-name "SiskiyouPlethodon", brand-short-name "Plethodon".
About dialogSiskiyouPlethodon 154.0.1 (ppc)Second line: "Built from Mozilla Firefox 154.0.1 source code for Arch POWER (powerpc). Not affiliated with or endorsed by Mozilla." That factual attribution is the only place the Firefox name appears.
Version154.0.1Follows the Gecko version exactly; no separate numbering. Our rebuilds increment the package release: 154.0.1-4.
Architectures(ppc) · (ppc64) · (ppc64le)One product name for every target; the architecture appears only in the About dialog and the package filename.
Development channelPlethodon EmberTest builds from the op64k tree. Package, binary, window identity and profile all become plethodon-ember, so it installs beside the stable build.
User agentunchangedThe Gecko user-agent string stays as built, including its Firefox/154.0 compatibility token, so sites keep serving the same pages. It names the engine sites test against, not the product.
Git tagsv154.0.1-4Package version as tagged; the release codename goes in the tag message, not the tag.
Release codenames

One Oregon wildfire per major version

Each Gecko major version gets the name of an Oregon wildfire, taken in order of the fire's year and alphabetically within a year. Codenames appear in release notes and tag messages only, never in the browser. The Biscuit Fire belongs to the product's story, so it's not in the list.
